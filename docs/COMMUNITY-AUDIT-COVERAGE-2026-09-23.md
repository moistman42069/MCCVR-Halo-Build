## Evidence preservation and limits

Local evidence is under `out/community-audit-20260923/` (ignored by git). `artifact-manifest.json` records original-file sizes and SHA256; `runtime-triage.json` indexes 63 log files, 59 unique hashes, including contributed diagnostic/launcher logs. `fault-index.json` retains contemporaneous module maps and first-chance exception locations. Duplicate files are not independent corroboration.

Downloaded logs were scanned in full for build/environment, lifecycle transitions, faults and recurring failure patterns, with relevant sections read. This is diagnostic triage, not a claim that every telemetry line proves a cause. Videos were visually sampled, not audio-transcribed or frame-by-frame certified. Discord calls have no accessible transcript. Deleted/inaccessible messages and unavailable GitHub repositories cannot be reconstructed. Search results sometimes initially showed unloaded authors; identities were not guessed.

No contributor binary was run. No game code, installed game files, accepted-build pointer, Discord messages or GitHub state changed during this audit. Detailed dependency review, engine verification, implementation and headset acceptance remain future work.
